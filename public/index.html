Sobre o armazenamento

O bot envia cada foto/documento/vídeo recebido no Telegram para o bucket configurado no Supabase (variáveis SUPABASE_URL, SUPABASE_SERVICE_KEY, SUPABASE_BUCKET) e grava a URL pública resultante no perfil do usuário (users/{'{uid}'}.documents[]) no Firestore. Se o Supabase não estiver configurado no bot, o link direto do Telegram é usado como fallback — esses arquivos aparecem marcados como "link direto" acima.

Vagas

Registro manual de vaga vista no site oficial — sem automação.

O bot não monitora nem automatiza o site oficial (VFS/consulado) — essa é uma decisão deliberada de design. Use esta tela somente depois que alguém da equipe checar pessoalmente que há vaga disponível para a rota. Ao confirmar, todos os usuários com consentimento e essa rota no perfil recebem um alerta.
